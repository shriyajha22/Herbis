# Project Overview

PrimeBrew Herbis is a modern Farm-to-Cup herbal tea e-commerce platform that enables customers to discover, purchase, and learn about premium herbal teas sourced directly from trusted farms.

The website must feel premium, natural, eco-friendly, trustworthy, and production-ready.

This is NOT a UI prototype.

Generate complete production-ready code with proper folder structure, reusable components, backend APIs, database integration, authentication, payment flow, admin dashboard, and deployment configuration.

The project should be scalable for thousands of users.

---

# Primary Goals

The website should

- Sell herbal tea online
- Showcase premium branding
- Educate customers about herbal teas
- Increase customer trust
- Provide secure online payments
- Offer smooth shopping experience
- Support future expansion
